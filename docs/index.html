Compare papers with evidence you can inspect.

A reproducible, AI-assisted pairwise workflow for making manuscript comparisons more structured, traceable, and stability-audited.

What the current evidence says.
In frozen project records, all 14 recorded position-reversal audits preserved the substantive direction (0 observed flips). These audits were not probability-sampled and do not estimate a general positional-bias rate.

How it works

01 · Prepare
Define the comparison purpose and freeze evidence cards.
02 · Compare
Record a verdict, decision hinge, confidence, and source locators for each pair.
03 · Audit
Reverse selected pairs to inspect stability. A reversal is an audit, not an extra vote.

Use the right interpretation

This workflow does not measure objective paper quality, predict acceptance, or establish a universal ranking. The current project evidence mainly describes practical internal stability. It does not include human-expert ground truth, and model families can disagree on near-tie comparisons.

Method · Validation evidence · Limitations · Source code

Use only manuscripts you are legally entitled to access. The documents remain local; this repository does not include benchmark papers.
